  Hard Hat Mack  (1984, Electronic Arts / IBM판 Dana How & Kevin Gilmore)
  C 변환판 + VGA 리마스터                          VGA REMASTER IN-HAK MIN
===============================================================================

[들어 있는 파일]
  HHMACK.EXE    원본과 똑같이 동작하는 판 (원본 HHMACK.COM 을 역어셈블해 C 로 옮김)
                화면도 원본 그대로 CGA 4색.
  HHVGA.EXE     VGA 256색 리마스터 판.  게임 규칙·빠르기·소리는 원본과 똑같고
                화면만 새로 그렸다 (단계마다 다른 하늘과 도시 배경).
  CWSDPMI.EXE   32비트 도스 실행에 필요한 도우미 - 두 판 모두 필요

  세 파일을 한 폴더에 두고 실행한다.  그림 자료는 실행 파일 안에 들어 있다.


[실행]
  도스 또는 DOSBox 에서
      HHMACK        원본 판
      HHVGA         VGA 판
  VGA 그래픽 카드가 필요하다 (DOSBox 기본 설정이면 된다).

  원본은 타이머 없이 CPU 빠르기로 돌던 게임이라, 4.77MHz IBM PC 의 빠르기에
  맞춰 돌린다.  더 빠르게 하려면 배수를 붙인다:
      HHVGA -2      두 배 빠르게   (-1 .. -8)

  느린 기계(386/486)에서는 화면 그리기가 게임을 늦추지 않도록,
  바뀐 곳만 조금씩 나눠 그리고 뒤처지면 그 장을 건너뛴다.
  (게임 빠르기가 먼저다 - 화면은 물결처럼 나뉘어 따라온다)
  486 에서는 원본 PC 속도가 거의 그대로 나오고, 386 에서는 조금 느리다.
  386 에서 원본 속도가 꼭 필요하면 CGA 판(HHMACK.EXE)을 쓰면 된다.


[조작]
  <- / ->           왼쪽 / 오른쪽
  위 화살표 또는 A  사다리 오르기
  아래 화살표 또는 Z 사다리 내리기
  스페이스          뛰기

  제목 화면에서
  1 / 2 / 3         해당 단계부터 시작
  Alt               키 설정 (조작 키 바꾸기)
  F10               조이스틱 맞추기 (글자 화면)
  F1                도스로 끝내기

  Ctrl+Q            언제든 도스로 끝내기 (C 변환판에 더한 키)
  Alt + ->          다음 단계로 (C 변환판에 더한 키)
  Alt + <-          앞 단계로
                    게임 중에는 점수와 목숨을 그대로 두고 옮기며 LEVEL 번호도 따라간다.
                    제목/시연 화면에서는 그 단계로 새 게임을 시작한다.
                    (Alt 만 눌렀다 떼면 원본대로 키 설정 화면)
